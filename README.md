## 🚀 SEO & WHY PROJECT STORM GOD IS THE BEST DISCORD AUTOMATION TOOL

Project Storm God is a highly advanced **Discord Automation Framework** designed to give you unprecedented control over your Discord account capabilities. Whether you're looking for a **Discord Music Bot using YT-DLP**, a way to **Use Custom Discord Emojis without Nitro**, a global **Sticker Manager**, or an **AFK Autoresponder**, Storm God does it all through an elegant, glassmorphic Web UI dashboard.

### ✨ Core Features

1. **😎 Nitro-Bypass Emoji Manager** 
   - Type `.efind` to instantly catalog every custom emoji in a server.
   - Use `.e <name>` or `.e <number>` to send custom emojis as high-quality image links anywhere—**no Discord Nitro required!**
   - Search across all your servers instantly with `.esearch`.

2. **🎨 Global Sticker Manager**
   - Easily scrape and save all custom stickers from any server using `.add sticker`.
   - Build a massive global collection (`.c`) and send stickers to any channel simply by typing `.sticker <name>`.

3. **🎵 YT-DLP Voice Channel Music Player**
   - Built-in YouTube music searching (`.msearch`) and high-quality voice channel audio extraction (`.mplay`).
   - Extract raw audio/video streams instantly with `.vcmusic` and `.vcvideo`.

4. **⚙️ Ultimate Utility Arsenal**
   - **Snipe (`.snipe`)**: Retrieve deleted messages instantly.
   - **AFK Mode (`.afk`)**: Set custom away messages.
   - **Keyword Auto-Responder (`.autoreply`)**: Automatically reply to specific phrases dynamically.
   
5. **🖼️ Premium Glassmorphism Help Renderer**
   - Type `.help` to generate a gorgeous, dynamically-rendered image dashboard utilizing Google Fonts and custom gradient UI cards.
   - Fully interactive Discord buttons for fast category navigation.

6. **💻 Real-Time Web Dashboard**
   - Control your active listeners, target channels, and automation loops from a stunning web-based GUI running on localhost.

## 📋 QUICK SETUP & DEPLOYMENT

### 1. Prerequisites
- **Python 3.10+**
- `ffmpeg` installed and added to your system PATH (required for music streaming).

### 2. Installation
Clone the repository from **rayzien**:
```bash
git clone https://github.com/rayzien/stormgod.git
cd stormgod
pip install -r requirements.txt
```

### 3. Configuration
Rename `config.example.txt` to `config.txt` and add your Discord user token:
```ini
[AUTH]
token = YOUR_DISCORD_TOKEN_HERE

[GENERAL]
prefix = .
```
*(Note: Never share your token with anyone. Self-botting is against Discord TOS. Use this tool responsibly and at your own risk.)*

### 4. Running the Engine
Start the backend and the Web UI simultaneously:
```bash
python main.py
```
Open your browser and navigate to `http://localhost:8085` to access the Project Storm God control panel.
